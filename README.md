# Grandma's Lambda

Grandma's Lambda is a private, family-run tool that keeps one YouTube playlist
fresh with recent videos from approved channels.

The app uses Google authorization to access the connected YouTube account. It
only uses that access to find or create the dedicated playlist, review its
contents, remove unsuitable entries, and add suitable videos.

The app is not offered to the public and does not show advertisements, sell
data, or share data for marketing.

See the [Privacy Policy](PRIVACY.md) for details.
